# Integrated Smart Campus Management System

## Review-II Development

This repository continues the work from Report-I by implementing and testing the selected DSA components.

See `README_REVIEW2.md` for the Review-II scope.

### Main implementation areas
- `unit2_graphs/` — graph algorithms for campus modelling and navigation
- `unit3_dynamic_programming/` — dynamic programming algorithms
- `data/` — campus graph and resource datasets
- `tests/` — Review-II verification
- `outputs/` — recorded verification results

Run the Review-II test suite with:

    python tests/test_review2.py
