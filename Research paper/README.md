## Relevance to the Project

The research paper is relevant to the campus-navigation component of the **Integrated Smart Campus Management System**.

The project involves modelling campus locations and their connections using graph-based concepts and studying shortest-path algorithms for navigation.

The reference therefore supports the project's study of:

- Campus navigation
- Location connectivity
- Graph-based modelling
- Shortest-path routing
